# UCI Iris Flower Dataset

This directory contains `iris.csv`, the canonical 150-sample Iris dataset (Fisher, 1936) with 4 numerical features (`sepal_length`, `sepal_width`, `petal_length`, `petal_width`) and 3 target species (`Iris-setosa`, `Iris-versicolor`, `Iris-virginica`).

Populated and verified in Phase 2 via `scripts/prepare_iris.py`.
